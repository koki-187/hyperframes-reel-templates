# 14DNA-ENGINE Quality Review Workflow

## 目的

レンダリング成功とデザイン完成を区別する。画像・動画は、生成された時点では候補であり、Premium Quality Gateで`RELEASE`以上と判定されるまで完成品ではない。

## 状態遷移

```text
queued
  ↓
processing
  ↓
review_required
  ↓
Premium Quality Review
  ├─ APPROVED → completed → 出力可能
  └─ REJECTED → rejected → 候補ファイル削除
```

## スマホからの審査

1. 通常作成画面または高度生成画面からジョブを作成する。
2. ジョブが`review_required`になるまで待つ。
3. `review.html`を開く。
4. Job IDを入力するか、直近ジョブを読み込む。
5. 7軸を0〜100で採点する。
6. 参考画像との差分とPremium Signalを入力する。
7. 重大エラー・警告を入力する。
8. RELEASE判定を実行する。

## 7軸採点の証拠

### Concept

- 投稿目的を一文で説明できる
- 主役となる価値が一つに絞られている
- 装飾が目的化していない

### Composition

- 視線の開始点と終点が明確
- 制御された非対称がある
- 主役と余白に緊張感がある
- 均等カード配置だけで構成していない

### Hierarchy

- 3秒以内に主メッセージを理解できる
- 主役、補助情報、CTAの優先順位が明確
- すべての情報が同じ視覚重量になっていない

### Materiality

- 光、素材、写真、CGに質感の根拠がある
- 単なる発光やグラデーションに依存していない
- 参考画像がある場合、素材密度と空気感が対応している

### Typography

- 日本語の禁則、改行、字間、行間が適切
- 文字切れ、文字化け、過密がない
- 正式フォントと正しい文字情報を使用している

### Brand

- 14DNAと対象ブランドの双方に一貫性がある
- ロゴ、色、トーンが正しい
- 一般的な生成AI広告に見えない

### Technical

- 出力サイズが一致
- セーフエリア内
- QR実読取とURL一致
- 固定アセットがAI生成されていない
- 可視ウォーターマークがない

## 承認条件

- 総合88点以上
- 全7軸70点以上
- 重大エラー0件
- 参考画像必須時は参考画像が提供されている
- 構図特性70以上
- 素材表現70以上
- 情報階層75以上

## 主観採点の禁止

次の理由だけで高得点を付けてはならない。

- 派手で目立つ
- 黒背景で高級に見える
- 情報量が多い
- AIらしい複雑な素材がある
- スマートフォンモックアップがある
- 巨匠名を連想できる

各点数には、画面上で確認できる根拠が必要である。

## 再生成方針

### 技術エラー

構図を維持し、固定アセット、文字組み、QR、サイズだけを修正する。

### Composition / Hierarchy不足

同じ候補を微修正せず、構成原理から作り直す。

### Materiality不足

背景の発光追加ではなく、主役素材、光源、表面特性、奥行きを再設計する。

### Template Feeling

カード数を減らし、主役を一つに限定し、余白と非対称性を再構築する。

## 出力禁止

`review_required`、`rejected`、`failed`、`cancelled`の成果物はダウンロード、共有、完成通知の対象にしない。

## 操作URL

- 通常作成: `/`
- 高度生成: `/advanced.html`
- 品質審査: `/review.html`

すべてTailscale内の認証済みRender Nodeから利用する。
